## Reproducibility archive (v1.0)

A fixed, versioned archive containing the complete data and scripts required to reproduce candidate selection and all post-selection analyses is available at the DOI above and in the `v1.0` release. The same files are organized in directory `R2_reproducibility/` in this repository:

| Directory | Content |
|---|---|
| `01_screening_scores/` | MEGADOCK scores, docking-derived Rosetta γ and co-folding-derived Rosetta γ for all 500 candidates (CSV), plus the candidate-level membership table for the consensus selection. |
| `02_library_properties/` | Chai-1 pTM and sequence properties (length, GRAVY, Shannon entropy, normalized entropy) for all 500 random mini-proteins. |
| `03_membrane_analysis/` | Membrane-occupancy summary for the four consensus candidates (fraction and volume of ligand atoms in the bilayer, buried residues). |
| `04_foldability/` | Per-candidate pLDDT, pTM, maximum PAE and inter-model RMSD from five independent single-sequence ColabFold predictions. |
| `05_mutation_scan/` | Raw FoldX PositionScan outputs at Ligand 66 residues 109 and 65 (ΔE = E_mut − E_WT). |
| `06_scripts/` | Python scripts used to generate the tables above from the raw data. |

The four final candidates are the three-way intersection of three parallel top-ranked sets applied to the 500-candidate library: MEGADOCK score top 20% (n = 100), docking-derived γ top 10% (n = 50) and co-folding-derived γ top 20% (n = 100). `build_selection_table.py` regenerates the candidate-level membership table from the three full-library score files.

## Complete scoring spreadsheet

`results/γ.xlsx` — complete scoring table for all 500 mini-protein candidates, including candidate ID, docking-derived Rosetta γ and co-folding-derived Rosetta γ. (The MEGADOCK score column is provided in `R2_reproducibility/01_screening_scores/megadock_scores-1.csv`.)

## 500 mini-protein structures

`chai--500_mini_proteins-0--250.zip` and `chai--500_mini_proteins-251--499.zip` — FASTA and PDB files of the 500 mini-proteins modeled with Chai-1, split into two archives for size limits. Together with the score tables above these files allow full reproduction of the consensus screening.

## Software versions

| Software | Version | Purpose |
|---|---|---|
| Chai-1 | v0.6.1 | Structure prediction |
| MEGADOCK | v4.1.1 | Rigid protein–protein docking |
| AlphaFold2-multimer (ColabFold) | 1.5.x (default AF2-multimer parameters) | Co-folding; single-sequence prediction |
| Rosetta | v3.14 | Relaxation / InterfaceAnalyzer |
| FoldX | 5.0 | Mutational scanning |
