# Claudin-18
The data and Results of AI-Driven Virtual Screening for Lead Mini-Protein Binders as Ligands of Claudin-18 
# chai--500mini_proteins-0--250.zip and chai--500mini_proteins-251--499.zip 
FASTA files and PDB files of 500 mini proteins modeled by chai.

# Candidate scoring results

- `results/γ.xlsx` — complete scoring table for all 500 mini-protein candidates, including candidate ID,docking-derived Rosetta γ, co-folding-derived Rosetta γ.

# Software versions

| Software | Version | Purpose |
|----------|---------|---------|
| Chai-1 | v0.6.1 | Structure prediction |
| Megadock | v4.1.1 | Rigid protein–protein docking |
| AlphaFold2-multimer | ColabFold 1.5.x (default AF2-multimer parameters) | Co-folding |
| Rosetta | v3.14 | Relaxation / InterfaceAnalyzer |
| FoldX | 5.0 | Mutational scanning |
